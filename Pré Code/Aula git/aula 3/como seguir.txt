Etapa 3
Abra o seu GitHub no navegador.
Clique na sua foto de perfil (canto superior direito) e vá em Settings.
No menu lateral esquerdo, clique em SSH and GPG keys.
Clique no botão verde New SSH key.
No campo Title, coloque um nome para você lembrar
No campo Key, cole o código que você copiou do terminal.
Clique em Add SSH key.

Etapa 4
no WSL enviar um "ssh -T git@github.com" para logar com a chave ssh
cd <pasta com os códigos organizados>
git clone git@github.com:<Usuário do github>/<repositório que vai trabalhar>.git --> buscar o respositório do github onde vamos trabalhar e baixar
